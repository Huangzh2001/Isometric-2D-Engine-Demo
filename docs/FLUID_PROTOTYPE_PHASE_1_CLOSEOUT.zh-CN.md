# Fluid Prototype Phase 1 收尾说明

## 阶段定位

本阶段完成的是“离散格流体原型”，目标不是最终真实水体，而是把流体从普通物体系统中拆出，并验证渲染、规则、占格、透明排序和调试流程。

## 已完成内容

1. **流体独立入口**：新增 `流体 / 渲染` 与 `流体 / 规则` 面板。
2. **水体渲染基础**：支持水体分层数量、顶面细分数量、连线插值曲线强度。
3. **逻辑 / 渲染分离**：逻辑层使用连续 `waterAmount`，渲染层按水体分层数量量化为 `renderWaterLevel`。
4. **局部流动规则**：实现同层扩散、空格生成水、删除极小水量。
5. **阻挡约束**：水只允许流入无非流体物体占据的同层格子，或向下流入无非流体物体占据的下层格子。
6. **重力优先下落**：简单 gravity-first cellular-automata 风格规则。
7. **对角穿墙约束**：禁止 diagonal corner cutting。
8. **透明渲染边界**：液体不应进入 solid occluder，可见面计算不能把液体当作实体遮挡物。

## 已知问题

1. 水面视觉仍偏原型，尚未达到成熟游戏水体效果。
2. 大量水格会快速增加 packet 数量，后续需要 dirty update 和数量上限。
3. 当前规则不包含压力、气体、温度、相变、真实表面张力。
4. 透明渲染与普通方块排序仍需要长期回归测试。

## 后续建议

短期不继续堆流体物理。优先做：

1. 固定 demo 场景库。
2. 一键清空全部流体。
3. 最大水格数量限制。
4. 鼠标悬停 cell 信息面板。
5. 流体规则调试 overlay。
