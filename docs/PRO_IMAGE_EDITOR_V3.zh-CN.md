# 统一图片编辑器 V3

## 定位

`start_editor.bat` 只打开一个统一素材编辑器。素材来源可以是普通图片、Habbo SWF 或未来导入器；导入后都转换为同一个“四方向 + 分层 RGBA”图片文档，再继续编辑公共 voxel 并统一导出。

Habbo 不是独立编辑模式。它只负责：

1. 将 SWF 中已有方向和图层转换为通用图片图层；
2. 为公共 voxel、占地与注册信息填写初始预设。

## 图片工作区

- 顶部：文件命令、撤销/重做、北/东/南/西方向切换、网格、注册点与专注模式。
- 左侧：绘图工具和当前工具说明。
- 中央：唯一的大型逐像素画布。
- 右侧：图层、颜色、属性三个检查器页签。
- 底部：坐标、尺寸、来源与操作提示。

四方向不再使用 2×2 大预览。顶部方向按钮包含小缩略图，点击后在同一中央画布中编辑该方向。

## 侧栏状态

左右侧栏均支持三态：

1. 展开：显示完整内容；
2. 紧凑：只保留高频图标；
3. 隐藏：完全释放画布空间，并在窗口边缘保留恢复把手。

按 `Tab` 可进入或退出专注模式。

## 功能

当前图片编辑功能包括：

- 四方向独立图层栈；
- 铅笔、橡皮、填充、取色、直线、矩形、移动图层；
- 图层新增、复制、删除、排序、锁定、显隐、命名和透明度；
- 普通图片导入、尺寸调整与颜色量化；
- Habbo SWF 分方向、分图层导入；
- 网格、注册点、平移、缩放和适应画布；
- 撤销、重做；
- `.hzhmat` 统一素材导入与导出。

## 视觉原则

界面参考乔布斯时代 Apple 专业桌面软件的原则：内容优先、清楚的实体控件、紧凑工具栏、Graphite 工作区、经典蓝色选中状态和渐进式披露。所有图标由项目自身 CSS 绘制，不读取网络图片，不使用现代毛玻璃或液态玻璃。
