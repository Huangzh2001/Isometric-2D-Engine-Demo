# 统一专业图片编辑器改版说明

版本：`20260806-pro-editor-v3`

## 本次完成

- 图片步骤改为单一大型逐像素画布。
- 北、东、南、西四方向改为顶部紧凑分段按钮，不再使用 2×2 大面板。
- 左工具栏和右检查器均支持展开、紧凑、隐藏三态。
- `Tab` 专注模式可释放全部画布空间。
- 右侧统一为图层、颜色、属性三个检查器页签。
- 增加移动图层工具与图层锁定。
- Habbo SWF 导入后直接转换为通用四方向分层 RGBA 文档。
- Habbo 推断的占地与注册信息继续写入公共 voxel/Prefab 状态。
- 删除独立 Habbo 校准画布和独立图层编辑区域。
- 使用项目自身 CSS 绘制工具图标，不包含网络图片资源。
- 视觉采用早期 Apple Pro Apps 的银灰工具栏、Graphite 工作区、实体控件和经典蓝色选中状态，不使用毛玻璃。

## 自动验证

- 四方向与通用图层模型；
- 逐像素工具和图层移动；
- 左右侧栏三态及专注模式；
- Habbo 分层转换为通用图片文档；
- 统一素材 RLE + gzip 导入导出；
- HTML ID、入口引用和 JavaScript 语法。

容器中的 Chromium 对本地地址和 `file://` 均返回 `ERR_BLOCKED_BY_ADMINISTRATOR`，因此 Windows 实机视觉和鼠标交互仍需通过 `start_editor.bat` 验证。
