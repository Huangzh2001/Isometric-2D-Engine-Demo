# 非破坏性图层平面

旧结构把每个图层强制存成与文档画布相同大小的 RGBA 数组。任何“移动后重新写回画布”的路径都会丢弃越界像素。

新版中每个图层独立保存：

```text
surface.x / surface.y   图层平面在文档坐标中的原点
surface.w / surface.h   图层自身尺寸
runs                    图层自身全部 RGBA 像素
```

文档画布只负责显示可见交集，不是存储边界。移动图层只改变 `surface.x/y`，不会重写像素。图层完全移出画布、保存、重新载入并移回后，像素字节必须完全一致。

绘图落在当前图层平面之外但仍位于文档内时，图层平面自动扩展，并保留旧像素。
