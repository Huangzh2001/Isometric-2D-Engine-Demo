# Shadow Projection Workbench v4.17.4 — HEIGHT COLUMN PROJECTION FIX

## 修复 v4.17.3 “高度代理存在但完全没有阴影”
用户日志显示 v4.17.3 已经成功生成高度代理：`nonEmptySlices=75`、`maxObservedH≈1.844`，但所有接收面都返回 `cells=0 / polys=0 / runs=0`。问题位于最后的 C(z) 逐层投影渲染，而不是四关键帧高度反推本身。

## 新的运行时投影
连续方法 A 的高度反推保持不变，但最终渲染改为直接投影高度场实体：

`O_H = {(x,y,z) | 0 <= z <= H(x,y)}`

每个 H(x,y) 网格单元作为一个小垂直柱：
1. 构造底面四顶点 z=0；
2. 构造顶面四顶点 z=H；
3. 方向光：沿 forward 与接收平面求交；
4. 点光源：沿 Light -> P 射线延伸到接收平面；
5. 八个投影点取 2D convex hull；
6. 所有柱投影取并集。

因此不再依赖 77 个高度切片逐层成功投影。即使某单元 H=0，它的地面 footprint 仍会保留，不会再出现整个影子为零。
