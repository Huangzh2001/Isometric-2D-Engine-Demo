# Shadow Projection Workbench v4.17.6 — KEYFRAME VOXEL INTERSECTION

## 这版改了什么

这版重写了 **A · 关键帧高度代理** 的反推数学，不再使用只对金字塔友好的

`h = min_i(extent_i * |d_z| / |d_xy|)`

近似。

现在改成更通用的 **四关键帧体素一致性反演**：

1. 对 footprint / fallback 区域中的每个候选体素 `(x,y,z)`；
2. 分别把它沿四个关键方向投到地面，得到四个落点 `q_i`；
3. 只有当四个 `q_i` 都落在各自关键帧 shadow 内时，这个体素才保留；
4. 对每个 `(x,y)` 取最高合法 `z`，形成单值高度代理 `H(x,y)`；
5. 运行时任意中间角度的阴影，仍由 `H(x,y)` 重新投影得到。

## 为什么要这样改

上一版实际上把“同一个地面点在四个方向的延伸长度取最小值”错当成了四关键帧反演。这对金字塔等规则物体还凑合，但对树、椅子、马桶等单图四方向复用素材非常容易把高度压成 0。

这版的体素一致性测试支持：
- 真四方向独立素材；
- 单图四方向复用素材（例如 tree 的 `single4-diagonal`）。

## 保留不变
- 四方向精确关键帧仍保留；
- Shadow Hull 仍保留；
- 高度代理的渲染仍使用“直接投影垂直高度柱”。
