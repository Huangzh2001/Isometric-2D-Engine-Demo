# v4.16.2 — Fixed-direction keyframe inspector

## 本版目标
先把“四方向精确关键帧”的检查流程做得更直接，方便逐个素材快速验证，而不是继续依赖拖动太阳去碰四个固定方向。

## 你这次要求对应的改动

### 1. 不再靠拖动选择四方向关键帧
- 在顶部工具栏新增一个很小的 **四方向按钮组**：
  - ↖ = NW
  - ↗ = NE
  - ↘ = SE
  - ↙ = SW
- 只有在 **四方向精确关键帧** 模式下才显示。
- 点击后立即切换到对应关键帧，并把太阳手柄吸附到该关键帧的真实相机射线方向。

### 2. 默认不再把大段说明文字摊开
- `showFormula` 默认关闭。
- 这样进入页面时右上角不会先出现大块文字面板，减少遮挡拖动的问题。
- 需要时仍然可以手动点“公式”按钮打开。

### 3. 更清楚地区分“平行光关键帧检查”和“点光源”
- 关键帧模式右侧增加一条很小的提示：**点光源暂不严格支持**。
- 原因：这四张关键帧本质上对应的是 **四个全局固定方向的平行光**。
- 点光源不是全局固定方向，地面上不同位置看到的光线方向都会变化，所以 **不能直接用同一组全局关键帧严格推出整张点光源阴影**。

## 结论
- 这版更适合做你说的那件事：**逐个素材检查四个固定关键方向到底行不行**。
- 但它还不是“点光源通用解”。
