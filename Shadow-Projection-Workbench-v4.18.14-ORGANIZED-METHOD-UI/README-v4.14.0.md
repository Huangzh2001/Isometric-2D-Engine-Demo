# v4.14.0 视图基准线投影

新增独立第六种方法：**视图基准线投影**。

核心：不估计 footprint。仍使用经典四向的方向选择与 SDF 连续 morph，但把中间 Sprite 放到一个竖直视图平面上；该平面与地面的交线就是“视图基准线”。

- 基准线方向 = 与当前视图/光照水平方向垂直（图片横向轴）。
- 基准线长度 = proxy 矩形沿该方向、穿过中心的截线长度。
- 斜四向：正方形 proxy 上会成为对角方向的中心截线。
- 正四向：会成为相对两边中点的连线。
- 不调用 footprint 推断，也不走 Footprint support 分支。
- 光照在两个方向之间时，继续复用经典四向 SDF morph，基准线随方向连续旋转。
