# Shadow Projection Workbench v4.11.1

## 新增：第五种阴影方法

本版本把之前实验性的 **Footprint 支撑边界投影法** 正式提升为一个独立的第 5 种阴影模式：

1. 纯 Voxel 阴影
2. 经典四向阴影
3. **Footprint 支撑边界阴影（新增独立模式）**
4. 高度图阴影
5. 四视图重建算法

## 第五种方法的核心思路

- 先从四向图片估计物体的接地 `footprint`
- `footprint` 本身先投成接触阴影
- 再根据当前光方向，求 `footprint` 的背光支撑边界
- 将图片中 `footprint` 基线以上的轮廓，从这条支撑边界投射到地面/接收面

## 目标

这个方法用于填补两类方法之间的空档：

- 比经典四向阴影更适合 **footprint 较大** 的对象（如金字塔、宽底座、斜坡）
- 比四视图重建算法 **便宜很多**，不需要完整 3D 重建

## UI 变化

顶部“阴影模式”按钮组中，新增：

- `Footprint 支撑边界阴影`

它作为独立模式存在，不再与“经典四向阴影”混在一起。
