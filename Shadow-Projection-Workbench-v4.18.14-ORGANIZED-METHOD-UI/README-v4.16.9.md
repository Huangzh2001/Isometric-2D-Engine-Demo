# Shadow Projection Workbench v4.16.9

本版继续针对用户指出的两个核心问题修正：

1. **四方向精确关键帧仍然有明显噪点**
   - 旧版 `keyframe` 模式把地面阴影先离散到世界网格再贴回地面，虽然快，但会出现颗粒、台阶和边界闪烁。
   - 新版改为：**直接在屏幕像素上回投到地面，再用原始关键帧 alpha 做全分辨率判定，只在边缘做 3×3 确定性 AA**。
   - 同时把用于 `keyframemorph` / `shadowhull` 的 ground-SDF 网格从 `0.028` 收紧到 `0.014`，降低台阶感。

2. **自由光源移动时的关键帧转换不自然，尤其是金字塔**
   - 本版继续坚持“**先绕物体 z 轴把关键帧阴影 transport 到当前方位**”这个原则。
   - 在此基础上，改成 **rotation-dominant** 方案：
     - 主体几何仍然来自旋转后的 ground-SDF；
     - 只加入少量旋转后精确 alpha 作为边界稳定项；
     - 边缘再做确定性 3×3 AA；
     - 过渡权重再次做平滑缓动，减少金字塔这类物体的“硬切感”。

版本字符串：`v4.16.9-exact-aa-rotation-dominant`
