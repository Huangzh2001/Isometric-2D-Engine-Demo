# v4.16.3 — Keyframe Shadow Hull Point-Light

## 这版改了什么
你前面说得对：
**“点光源暂不严格支持”是个很严重的问题。**

所以这一版我做的不是继续硬改“原始四方向关键帧地面投影”，而是把
**四关键帧 → Shadow Hull → 点光源遮挡测试**
这条链条真正接上。

---

## 原理

### 1. 原始“四方向精确关键帧”本身仍然只是平行光检查工具
它的本质是：
- 固定 4 张方向图
- 每张图对应一个固定相机射线方向
- 在“光线方向 = 这张图的相机射线方向”时，可以直接把地面点回投到这张图上判定阴影

所以它天然适合：
- 固定的平行光方向
- 地面关键帧验证

但它**不天然适合点光源**，因为点光源对不同地面点的光线方向都不同。

---

### 2. 这版如何支持点光源
这版改成：

1. 先对四个关键方向分别生成严格地面阴影；
2. 把每张地面阴影沿对应关键帧的相机射线反向挤出，形成 3D 约束柱体；
3. 四个柱体求交，得到一个 **shadow visual hull**；
4. 判断任意接收点 Q 是否在阴影中：
   - **平行光**：沿当前太阳方向反向追踪；
   - **点光源**：沿 **Q → 点光源** 的线段追踪；
5. 只要这条光线与 shadow hull 相交，就认为 Q 被遮挡、落在阴影里。

所以这一版的点光源支持，不是“随便挑一张图去投影”，而是：
**先重建一个可遮挡体，再做真正的遮挡检测。**

## 你使用时怎么测
### 推荐方式
1. 打开页面
2. 保持模式在 **关键帧 Shadow Hull**（默认就是这个）
3. 把光源切到 **点光源**
4. 拖动点光源位置，看阴影是否跟着变化

### 说明
- 原始 **四方向精确关键帧** 模式依然保留，作为“固定四方向检查器”使用；
- 如果你要看 **点光源是否支持**，请主要看 **关键帧 Shadow Hull** 模式；
- 这条路线比单张关键帧地面投影更重一些，但理论上更通用。
