# v4.16.4 — Four-Keyframe Preview Fix

本版针对“四方向精确关键帧”检查流程做三项修正：

1. **左上 HUD 默认关闭**
   - 页面启动时不再显示大块 HUD 文本。
   - 顶部保留 `HUD` 按钮，需要时再打开。

2. **四方向直接显示为可点击缩略图**
   - 四个固定方向直接显示对应素材缩略图：NW / NE / SE / SW。
   - 点击缩略图立即切换关键帧并把太阳手柄吸附到对应方向。
   - 真八向素材使用真实的 `NE / SE / SW / NW` 四张对角图。
   - 普通四向素材使用自己的四张方向图。
   - 单图素材会诚实地显示同一张图在四个方向复用。

3. **四方向检查覆盖所有非人物方向模型**
   - `diagonal4`
   - `terrain-diagonal4`
   - `single4-diagonal`
   - `oct8`（固定取 NE / SE / SW / NW）
   - 人物仍不纳入这一轮静态物品检查。

如果当前激活的关键帧计算结果为 0 阴影像素，当前缩略图会显示红色边框，便于快速定位“完全生成不出来”的素材/方向；缺失素材则变灰。

点光源仍请使用 **关键帧 Shadow Hull** 模式；原始四方向关键帧模式保留为固定平行光关键帧检查器。
