# VALIDATION v4.17.3

## 本版应该重点人工检查的内容

1. **四关键帧端点是否仍严格回到精确关键帧**
   - 把太阳拖到四个关键方向附近；
   - `keyframemorph` 模式下，端点处应直接显示精确关键帧结果。

2. **中间角度是否不再表现为“整张影子旋转/融化”**
   - 在 `keyframemorph` 模式下连续拖动太阳；
   - 观察阴影是否更像由内部高度代理重新投影得到，而不是直接形状插值。

3. **Shadow Hull 是否仍可独立选择**
   - 连续方法 B 应继续可选；
   - A/B 切换应正常。

4. **性能是否仍可接受**
   - 新方法在拖动时会重投影切片；
   - 重点观察是否出现明显更严重卡顿。

## 已知限制
- 该方法当前更偏向“单值高度代理 H(x,y)”；
- 对树冠、悬空结构、空洞结构，可能仍不够；
- 点光源目前允许手动试用，但主设计目标仍是由四个平行光关键帧反推连续方向阴影。
