# Shadow Projection Workbench v4.13.1

## 本次重点
这版不再保留“固定线投影”。重点回到 **Footprint 估计本身**。

## 改动
- 移除固定线投影按钮。
- 保留 Footprint 查看器。
- 金字塔等规则素材：继续保留旧的可见边收缩法。
- 其他素材：新增 **下边缘回投 + hull(凸包)** 的 footprint 估计法。

## 新估计法
1. 对每个方向图提取下边缘轮廓。
2. 将这些下边缘像素反投影到 z=0 地面局部坐标。
3. 聚合多个方向图的地面点。
4. 对点集做鲁棒过滤，然后取 convex hull，作为 footprint。

## 目的
先把 footprint 估计尽量做对，再谈后续阴影形状。
