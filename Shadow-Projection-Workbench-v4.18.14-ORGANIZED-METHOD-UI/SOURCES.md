# 测试素材来源

本实验的目标是测试二维 sprite alpha 在等距世界中的多接收面阴影投影。

## 用户素材

- `bathroom_toilet1.hzhmat`：用户提供。
- `assets/toilet_f0.png` ... `toilet_f3.png`：由该素材中提取，测试时去掉原素材自带的地面阴影层。
- 真实 registration：`(35, 78)`，来自 `.hzhmat` 的 `prefab.habboCalibration.registrationPx`。

## 网络 CC0 测试素材

实验素材浏览器还列出 30 个 Kenney 等距 PNG，按需从以下公开镜像加载：

- 上游作者：Kenney
- 许可：CC0 1.0 / Public Domain
- 官方许可说明：https://kenney.nl/support
- 主要素材包：https://kenney.nl/assets/isometric-tiles-landscape
- 城市素材：https://kenney.nl/assets/isometric-tiles-city
- 建筑素材：https://kenney.nl/assets/isometric-tiles-buildings
- GitHub CC0 镜像：https://github.com/tursics/isometric-icons

网络素材不打包进 ZIP，以保持实验项目很小；打开实验时需要联网才能加载这些 30 个样本。本地马桶、树、路灯、雕像可离线使用。
