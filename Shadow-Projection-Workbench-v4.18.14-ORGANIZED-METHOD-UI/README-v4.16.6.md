# v4.16.6 — Keyframe UV Bounds Fix

## 根因
“四方向精确关键帧”会对整个接收地面逐点回投到源图。

旧代码在回投坐标落到源图外时，仍调用 `sampleAlphaBilinear()`。
这个通用采样函数会把坐标 clamp 到图片边缘。

对于金字塔，图片边缘是透明的，所以问题不明显。
对于 Kenney 水渠，alpha 直接碰到 PNG 边界，于是边界上的不透明像素被
无限复制到源图外，最终在地面上形成一条或多条很长的假阴影带。

这也解释了为什么“经典任意移动方向”此前不明显：经典路径先限制了投影
bounds，不会在整个地面上无界回投。

## 修复
`sampleExactKeyframeAlpha()` 现在严格执行：

- 回投 UV 在源图内部：正常双线性采样；
- 回投 UV 在源图外：直接返回 0（透明）；
- 不再把源图边缘像素复制到整个世界地面。

水渠仍被当成完整的立体“蛋糕”参与投影，没有删除顶面、侧面、水渠或任何
所谓“地面部分”。

该修复同时影响：
- 四方向精确关键帧
- 关键帧地面 SDF
- 基于这些关键帧构建的 Shadow Hull
