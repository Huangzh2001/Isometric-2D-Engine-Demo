# Shadow Projection Workbench v4.13.2

## 这版只集中修 Footprint 估计

固定线方法已从界面移除。本版核心问题是：之前的下边缘算法把树冠、灯罩、桌面等悬空轮廓也当成了 z=0 接地点，所以 footprint 会被严重放大。

### 新方法：最低接地簇 → z=0 回投 → hull

1. 对每个输入方向图逐列取 alpha 下边缘。
2. 计算这些下边缘相对全图最低点的垂直距离。
3. 自动寻找最低一簇与上方悬空轮廓之间的距离跳变；只保留最低接地簇。
4. 把这批像素反投影到 z=0 地面。
5. 汇总多方向结果并取 convex hull。
6. 金字塔继续保留原本效果较好的 visible-edge shrinkwrap。

### 查看器增强

Footprint 查看器新增紫红色点：这些点就是算法真正用于估计 footprint 的接地点。
